Baris pertama file harus jadi header kolom, minimal ada kolom nama dan satuan. Kolom kategori, barcode, stok (stok awal, angka), dan minimal stok (angka) boleh ditambahkan (opsional). Nama kolom tidak case-sensitive. Kolom stok hanya untuk stok awal — kalau barangnya sudah ada, re-import tidak akan menimpa stok yang sudah berjalan kecuali kamu isi ulang kolom itu. Kolom minimal stok juga begitu, cuma ditimpa kalau memang ada isinya di file.
